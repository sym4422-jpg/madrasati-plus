# منصة مدرستي بلس — تطبيق غير رسمي

تطبيق Android WebView يفتح https://schools.madrasati.sa/ . لا يتبع وزارة التعليم أو منصة مدرستي، ولا يجمع كلمات المرور في خادم خاص.

## بناء APK مجانًا باستخدام GitHub
1. أنشئ مستودع GitHub جديدًا، ويفضل أن يكون Private، باسم madrasati-plus.
2. فك ضغط الملف ZIP وارفع **محتويات** المجلد إلى جذر المستودع (وليس المجلد نفسه). تأكد من وجود `.github/workflows/build-apk.yml` في جذر المستودع.
3. افتح تبويب Actions في المستودع، ثم اختر Build Android APK ثم Run workflow.
4. بعد نجاح المهمة، افتح تشغيلها وحمّل ملف madrasati-plus-debug-apk من Artifacts.
5. فك ضغط ملف artifact، وستجد app-debug.apk للتثبيت على جهاز Android.

يمكن أن يبدأ البناء تلقائيًا عند رفع الملفات إلى فرع main أو master. إن لم يظهر سير العمل، تأكد من رفع المجلد المخفي `.github` وتمكين Actions.

## ملاحظات مهمة
- هذا APK تجريبي موقّع بمفتاح Debug، وليس إصدارًا للنشر على Google Play.
- المصادقة عبر Microsoft قد ترفض WebView؛ استخدم زر «فتح في المتصفح» عند الحاجة.
- الاختبارات والواجبات والرفع والتنزيل والحصص تحتاج اختبارًا عمليًا، ولا يمكن ضمان التوافق مع كل ميزات الموقع.
- الملفات المنزلة تُحفظ في مجلد التنزيلات الخاص بالتطبيق، وقد لا تظهر في تطبيق الملفات العام.
